已有公开 `comment/backend` 本身包含宿主边界，本次不借更新扩大公开范围。`social_feed/host_runtime.py` 需要显式配置宿主；公共 HTTP 工厂需要兼容的 `runtime.social_security_types`，公共 MCP 工具需要 `runtime.require_social_visitor_id`。未接入时明确失败，公共监听器不自动启动。部署者不能绕过这些条件直接暴露管理接口。

## 复核关注点

剥离过程中存在 AST 格式重写，文件差异较大；需要独立检查调用合同与语义。已修复确认的备用视觉客户端、音频清理、旧调度中间消息、Builder 导入及日历广播分支问题。剩余 6 项静态名称告警为受 locals() 保护的变量和字符串类型注解，未当作已确认运行故障；独立审核仍可复查。

保留历史来源兼容过滤不代表仍提供对应私有功能。JWT 的 `scp` claim 是权限范围字段，与被排除的 SCP 认知模块无关；感知应用映射中的淘宝包名也不等于淘宝执行模块。
