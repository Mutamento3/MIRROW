## 本次发布适配及修复

- 把普通工作准入、通用界面消息、网络目标检查和本地密钥保护从未公开应用边界分离，避免保留模块依赖会客／淘宝执行引擎。
- 四路日结的名称、任务和结果保持一致；工具、上下文、漫想目录同步剥离排除功能。
- 修复副本中发现的日历刷新广播目标、时间原料导入、Builder 链式调用导入、视觉备用请求客户端、音频临时文件清理导入，以及旧调度路径的中间消息 ID 依赖；不会反向修改生产代码。
- 用户回复通知读取已初始化的任务管理器，不在接口内隐式新建实例；分别记录漫想通知与任务通知结果。
- 移除旧固定角色自启动、群聊后台协作、默认第三主体、私人相识时间及固定工作作息。
