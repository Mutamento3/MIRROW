# 2026-10-18 公开模块更新

本次在既有公开仓库上增量同步，保留 2026-10-13 日常闭环及后续模型来源功能，不复制私人生产数据库、环境配置、账号、设备或身份。不是生产项目的全量镜像，也不新增私人独立模块。

## 实际变更

| 范围 | 本次同步 | 接入边界 |
| --- | --- | --- |
| 漫想 V3 | 新自主计划预计数量、节点显式续延、换活动目标、持久化与重启恢复 | 宿主已注册事件内自主；固定目标、真实计时、截止、中断、失败仍有效 |
| 身体说明／上下文 | 由公开目录生成事实投影；完整身体材料与已启用处理器分开 | 保持稳定首 system；没有设备不声称有感知能力 |
| 自省 | 当前愿望与反思保留；停止额外写入长期自我候选 | 长期认知由既有日结链维护，旧候选不删除、不迁移 |
| Memory V2／召回 | 混合时间归一化、召回请求附加字段保留 | 历史 naive 时间明确按 UTC+08:00；不重写事件、认知或历史消息 |
| 哨兵 | 客观观察与主观联系念头区分；地点新鲜度与推测标记 | 既有来源核验、聊天抢占和真实交付不变；缺失设备仍未知 |

| 工具／本地前端／日结 | 复核兼容性并跑回归，保留现有公开接线与模型来源记录 | 未迁入私人行动编译器、全量生产 UI 或私人认知源 |
| 共域／共享耳蜗 | 保留现有公开模块及真实回执、独立接入方式 | 本次无功能代码变化；非默认宿主自动启用，耳蜗原有第三方许可不变 |

会客、淘宝继续只有接口并保留 AionsHome 来源声明；未发布的独立模块不在本次发布范围。

## 迁移与兼容

- 新策略保存在现有 run 快照中；无标记的旧 run 保留原有限额与截止语义。
- 数量续延必须来自成功节点复核，单纯返回 continue 不会偷偷增加配额。数据库失败不会只保存数量而漏掉节点终态。
- 自省停止创建新的长期候选，但不清除旧数据，兼容 API 仍可读取。
- 身体事实是可重建说明，不是额外的人格权威；当前启用能力与调用回执继续由宿主提供。
- 小红书旧入口保留；新入口需按[接入合同](XHS_READ_ONLY_TASKS.md)单独挂载。
