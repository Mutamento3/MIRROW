# 公开骨架架构边界

主聊天保存真实消息与附件身份。上下文组装读取各领域的事实投影，供应商适配负责实际请求；事实材料、来源、时间与输出合同分开。不会因剥离私有模块而补造其经历或回执。

Memory V2 使用真实来源构建可追溯的经历与召回；认知书是派生认识，不替代原话。公开日结包含 world、self、interest、other 四路，任务、结果和状态使用一致顺序；没有 SCP 生产或消费入口。

漫想和哨兵依赖实际注册能力与真实运行状态。事件目录、身体能力说明、工具注册及上下文按本包范围收敛。未配置的模型、设备和宿主功能保持未知或不可用，不生成成功回执。

`body_admission.py` 管理进程内前台活动与普通工作准入；它从会客领域中分离，供主聊天、共域、小红书和工坊自身使用，不包含会客执行引擎。`ui_action_messages.py` 保存通用界面动作消息，不包含淘宝工作流。

共域的业务和存储保留既有公开范围；`host_ports.py` 声明宿主合同，`host_runtime.py` 显式注入宿主。身份验证、限流和访客身份解析来自真实接入，不在公开骨架中使用默认放行。通用网络目标校验、密钥本地保护与管理端检查分别由独立模块承担。

前端只呈现保留能力；会客／留言入口明确未接入。普通图片理解与消息附件保留，图片生成及形象锚点不属于本包。Android 采集实现和应用源码与运行数据、设备密钥、构建签名分离。

整个副本与生产目录独立；无历史数据迁移、生产数据库操作或远端发布步骤。
# 候选审核修正边界

主后端默认仅本机监听和访问；远程设备由部署者显式登记，主设置接口不是公共入口。主应用统一 ASGI 边界覆盖全部 HTTP/WS，网络准入与浏览器显式 Origin 校验分别成立；CORS 共享该来源表，不代替实际准入。共域公共宿主配置在显式创建公共应用时校验，不阻断本地模块导入，原有鉴权与限流仍必须接入。

快捷邀请沿消息权威写入、回执校验、会话投影确认后才广播。所有可选路由和依赖注入均在直接启动服务器之前完成。电脑摄像头需明确设备索引；工坊模型合同仅描述公开的代码创作、文字与已有素材能力。
