# 目录验收清单

## 顶层

| 路径 | 用途 |
| --- | --- |
| `ai-chat-backend/` | 主聊天、上下文、记忆认知、感知行动与各公开能力的后端源码 |
| `ai-chat-frontend/` | Web／Capacitor 前端与 Android 主应用源码 |
| `android-input-helper/` | Android 文本输入及通知信号辅助源码，不含签名与安装包 |
| `android-step-bridge/` | Android 步数采集辅助源码，不含本机配置与安装包 |
| `LICENSES/` | 第三方完整许可 |
| `docs/` | 范围、更新、架构、验证与文件清单 |

## 核对重点

- 记忆、认知、日结、心情、哨兵、漫想和工具保留实现；个人书页和记录不带。
- 音乐耳蜗维持已有公开范围，不把布局整合说成新音乐功能。
- 感知数据源实现保留，包括手机、通知和手环相关采集；设备配置、配对信息和历史采样不带。
- Memory V2 中的 AionsHome 派生日期与检索逻辑保留，来源见第三方声明。
- 共域／朋友圈对照原 `comment/backend` 范围，保留既有宿主接入边界，不扩展会客、群聊或桌游实现。
- 会客室和留言板只是未接入的扩展位置与状态／失败响应，不是完整功能。
- 小衣柜、心灵分析室、小剧场、生图、宝典、SCP、淘宝、QQ、跨家群聊／桌游、旧本地群聊／后宫不分发。
- 工坊保留非生图制作与展示；私人形象锚点和定制场景图不带，界面使用通用图形。
- Toy 命令保留，默认设备地址为空。普通图片理解和附件不属于生图途径。

## 不应出现的内容

`.env`、凭据、签名、数据库、聊天／认知正文、设备绑定、私有服务地址、私人头像照片、音视频、缓存、日志及生产备份均不属于发布内容。

私有导出脚本、扫描词表、原始来源清单与审核工作文件放在本副本之外，不随源码发布。`SOURCE_MANIFEST.json` 仅记录本候选的相对路径、大小和哈希，不包含生产绝对路径。

发布范围以冻结源码清单及对应 Git 提交为准；构建和运行产物不随源码发布。项目主人授权独立审核修正后发布，不代表已进行逐文件人工目录验收。
