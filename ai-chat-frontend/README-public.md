# 前端骨架副本

本目录是 2026-10-24 待审源码，不是生产部署目录，也尚未发布。

聊天、记忆与认知、心情、日结查看、日历、共域、许愿板、音乐耳蜗及工坊非生图部分保留源码。会客室和留言板仅提供无网络副作用的未接入说明。QQ、淘宝、跨家群聊／桌游、旧本地群聊与后宫、小衣柜、心灵分析室、小剧场、图像生成与其相册、米拉宝典、SCP 入口与消费不分发。普通图片上传／理解和消息附件显示不属于图像生成，仍保留。

不附带账号、对话、画像、提示词人设、个人头像、图片、设备绑定数据或构建包。工坊定制场景改用通用图形，手机和 Web 图标使用本副本的新通用矢量图。后端能力仍以对应接线实际可用状态为准，前端构建成功不代表整个系统部署验收通过。

## 验证

```
npm ci --ignore-scripts
node --test tests/public-scope.test.mjs
npm run build
```

Android 感知采集和手环源码按本轮范围保留，AionsHome 派生代码保留来源声明及 MIT 许可。普通录音 WAV 编码沿用 AionsHome 来源，音乐模块沿用既有公开范围及其许可证。Toy 命令保留，默认 MAC 为空；未配置真实设备时返回失败，不能把命令发送当成设备状态已改变。

Android 尚未进行 SDK/Gradle 编译或设备实测。纯源码筛选不附带本地 SDK 配置、签名文件、APK、Gradle wrapper 二进制或生成的 Capacitor assets。部署者需要本地 Android SDK/JDK，并安装对应 Gradle、生成 wrapper、执行 Capacitor sync 后构建；不能把本目录直接当作可安装 APK。前端 API 联调等待后端副本审核。
