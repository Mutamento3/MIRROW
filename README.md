# MIRROW · 本地单用户源码骨架

本轮源码以 2026-10-24 导出版本为基础，包含 2026-10-25 独立审核后的发布修正；不是私人生产目录的原样镜像。请先阅读 [目录与范围](docs/DIRECTORY_REVIEW.md)、[更新说明](docs/RELEASE_DRAFT.md)、[部署条件](docs/DEPLOYMENT.md) 和 [验证边界](docs/VERIFICATION.md)。

MIRROW 面向各自部署的本地单用户：主聊天、上下文、记忆与认知、感知和行动共同构成持续运行的系统。本包提供实现与接入边界，不附赠已经配置好的模型、人格、记忆或设备。

## 源码范围

保留主聊天与消息检索、上下文组装、Memory V2、认知与四路日结、心情、习惯与挂念、日历与任务、漫想、哨兵及感知采集、音乐耳蜗、语音、许愿板、小红书、工具与非生图工坊等源码。普通图片上传、理解和附件展示保留。

共域／朋友圈以既有公开包为范围，对照当前代码同步修复；仍使用明确的宿主接口，不随包提供会客引擎。会客室和留言板仅留未接入的扩展说明／状态边界，不代表已具备完整接入实现。

不包含小衣柜、心灵分析室、小剧场、生图途径、米拉宝典、SCP 日结及消费链路、淘宝、QQ、跨家群聊／桌游、旧本地群聊和后宫入口。

不包含聊天、画像、认知书正文、日记、相册、录音、声纹、设备绑定、账号、密钥或私人配置。少量随附字体与装饰素材来自此前已公开的通用资源，出处与许可随包保留，不是个人相册。

## 配置与运行边界

后端直接启动默认仅监听 `127.0.0.1`，空访问配置也只允许本机 IPv4/IPv6 回环。手机接入须自行设置监听地址 `HOST` 并登记可信客户端 `ALLOWED_IPS`，或配置既有局域网设备校验；这些是具有本机控制能力的可信设备，不应向公网开放主后端或设置接口。电脑摄像头需设置 `CAMERA_DEVICE_INDEX` 或调用时明确索引，`CAMERA_DEVICE_NAME` 仅为可选标签，无默认设备名。

前后端默认后端端口统一为 `8005`。主应用全部 HTTP/WebSocket 连接统一核验网络准入；浏览器额外核验显式来源，远程前端需配置 `ALLOWED_ORIGINS`。`CORS_ALLOW_ALL` 不再开放来源边界。主后端现行整合链以 Windows 为支持前提，其他平台需适配 Windows 设备工具，不能仅凭 Python 安装成功认定可用。

- 后端入口在 `ai-chat-backend/main.py`，依赖清单在该目录的 `requirements.txt`。先创建独立虚拟环境并安装依赖，再按自己的模型、设备和可选服务配置运行。当前没有完成干净环境安装、完整主入口启动或日结生命周期联调，不能把源码检查结果当成开箱即用保证。
- Web 前端在 `ai-chat-frontend`。可执行 `npm ci --ignore-scripts`、`node --test tests/public-scope.test.mjs`、`npm run build`。桌面浏览器默认连接本机后端；手机端需要自行配置后端地址。参见该目录 `.env.example` 和 `README-public.md`。
- Android 源码不附本机 SDK、签名、APK、模型权重或生成的 Capacitor 资源；需要部署者自行准备构建环境。两个 Android 辅助项目同样仅提供源码。
- 设备命令需要真实设备配置；Toy 没有默认 MAC。未配置状态不代表命令已经执行。感知数据、语音模型和历史记录由部署者在自己的环境中产生。
- 共域公共监听器不会自动启动。其身份验证、限流和宿主访问仍须通过 `social_feed/host_ports.py` 与 `host_runtime.py` 接入；缺少接入时明确不可用，不以放行代替鉴权。
